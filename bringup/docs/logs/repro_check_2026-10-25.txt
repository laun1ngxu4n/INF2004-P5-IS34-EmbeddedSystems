P5-IS34 bring-up - image reproducibility check
Date: 2026-10-25. Same toolchain as the original builds: arm-none-eabi-gcc (15:13.2.rel1-2) 13.2.1 20231009,
Pico SDK 2.1.1 (git bddd20f), board pico_w.

Method: build the v3.1 source (P5-IS34_bringup_tests_v3.1.zip, unchanged) with SOURCE_DATE_EPOCH set to
the original build day, so the compiler's __DATE__ string matches, and compare every .uf2 byte for byte
with the prebuilt images that were flashed and tested. Without the date setting the only difference is
that date string (1-2 bytes per image).
